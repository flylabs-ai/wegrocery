# PWA base rollout (W1a)

The web app manifest drops its portrait lock. Existing installations pick up the
change when the operating system rereads the manifest. Verify this on iOS using
an icon installed before the update. Record whether it still opens the app
without reinstalling and whether the app follows the device in landscape.

The app composes its manifest and viewport so the existing fields and brand
colours stay the same. It supplies the existing icon paths to the FlyLabs Kit
PWA module. The app keeps its existing handling of backslashes in local logo
filenames during adoption.

An anonymous request for /sw.js reaches Next.js routing. It returns 404 until
the worker ships. The nightly UI check also accepts 200 for that later rollout.

There is no configuration or migration to apply. To revert, roll back the app
release. The operating system updates manifest metadata when it rereads it.
